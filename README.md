# Othello AI Backend

Python / FastAPIで実装したオセロAI対戦Webアプリのバックエンド

## 概要

8×8オセロのゲームロジックとDQNで学習したAIモデルを管理し、FastAPIを通してフロントエンドにゲーム状態を提供します。

## 主な機能

* オセロ盤面の管理
* 合法手判定
* ユーザーの着手処理
* DQNモデルによるAIの着手選択
* パス処理
* 勝敗判定
* 石数の集計
* ゲームのリセット
* フロントエンド向けREST API

## 使用技術

* Python
* FastAPI
* PyTorch
* NumPy

## API

### `GET /board`

現在の盤面情報を取得します。

### `POST /move`

ユーザーの着手を受け取り、ゲームを進行します。

送信例:

```json
{
  "action": 19
}
```

レスポンスには、ゲーム状態、盤面遷移、合法手などを含みます。

### `POST /reset`

ゲームを初期状態に戻します。

## AIモデル

学習済みのPyTorchモデルを読み込み、推論時には探索を行わず、各合法手のQ値から着手を選択します。

モデルファイルは所定のモデルディレクトリに配置します。

## セットアップ

依存関係をインストールします。

```bash
pip install "fastapi[standard]"
```

必要なPythonライブラリを別途インストールしてください。

FastAPIを起動します。

```bash
fastapi dev api/main.py
```

APIドキュメント:

```text
http://127.0.0.1:8000/docs
```
